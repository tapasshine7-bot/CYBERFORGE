# CYBERFORGE Study Library Source Basis

The Study Library will use short original explanations and browser-local exercises rather than reproducing external documentation. Its safe scope is informed by the following official reference points.

| Reference | Relevance to CYBERFORGE | URL |
| --- | --- | --- |
| Kali Linux documentation | Kali organizes official material around installation, ARM and mobile use, tools, post-installation, and troubleshooting. CYBERFORGE will present only command concepts and authorized, contained practice. | https://www.kali.org/docs/ |
| Termux documentation | Termux describes its documentation as a work in progress and directs readers to its wiki as the primary documentation location. CYBERFORGE will explain mobile shell concepts without accessing Android APIs or storage. | https://termux.dev/en/docs/ |
| OWASP Web Security Testing Guide | OWASP describes the WSTG as a comprehensive guide for web application and web-service security testing, with versioned scenario identifiers. CYBERFORGE will use the methodology only for legal scope, defensive review, and reporting concepts. | https://owasp.org/www-project-web-security-testing-guide/ |

> CYBERFORGE practice material is educational, browser-local, and limited to systems learners own, have explicit written authorization to test, or that are deliberately vulnerable training labs.
