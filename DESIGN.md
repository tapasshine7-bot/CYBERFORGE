# CYBERFORGE Product Design

## Brand Essence

**CYBERFORGE is a guided cyber-practice workspace for learners who want to build real defensive skills without leaving the legal boundary.** Its personality is disciplined, technical, and composed.

## Design Direction: Containment Console

The interface uses a dark graphite workspace with a restrained electric-lime signal color, warm white type, and small amber warning states. It avoids gaming-style neon overload. The structural motif is a contained operations console: a persistent left rail, a compact status strip, field-log cards, and one large active workspace rather than a generic centered marketing layout.

The type system pairs **Space Grotesk** for labels and navigation with **IBM Plex Mono** for terminal output, metrics, and system messages. The signature colour is **Forge Lime (#B7F34A)**. Motion should feel utilitarian: narrow scan-line pulses, status indicators, and quick 160–220 ms transitions that respect reduced-motion preferences.

## Information Architecture

The first dashboard contains six working areas: Overview, Practice Terminal, Learning Paths, Defensive Tools, Knowledge Base, and Progress. It uses representative lab content rather than fake live security claims. A terminal session card clearly states that the current practice target is isolated and simulated.

## First-Release Features

| Area | Functional experience |
|---|---|
| Overview | Readiness score, active module, activity feed, and the next safe lab. |
| Practice Terminal | Simulated Linux filesystem and allow-listed commands such as `help`, `ls`, `pwd`, `cat`, `whoami`, `ip addr`, `find`, `grep`, and `clear`. |
| Learning Paths | Structured foundations, defensive web security, incident-response basics, and authorized lab methodology. |
| Defensive Tools | Local hash calculator, password-strength checker, URL-format risk checklist, and security-header explainer. |
| Progress | Local-only completion states and badges so the user can practise without creating an account. |

## Wordmark and Logo

The mark is a compact angular shield/terminal-cursor glyph with a cut-out forge spark. The wordmark is built from letter-spaced Space Grotesk rather than a default font. The logo will remain text-free as an icon asset where required.
